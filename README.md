# 電路數學工具箱 v2

電路與工程數學計算器，涵蓋交流、直流、元件、雙埠網路、波德圖與濾波器，結果都可一鍵複製。

**線上使用**：https://kftseng2oo1.github.io/circuit-math/

## 分頁與功能
- **交流 AC**：複數四則運算、直角 ↔ 極座標轉換、相量圖、串並聯阻抗、功率（S/P/Q/PF，判斷感性或容性）、RLC 諧振（f₀、Q、頻寬）
- **直流 DC**：歐姆定律自動求解、分壓／分流、Δ–Y 轉換、電阻串並聯
- **數學工具**：表達式計算、2×2／3×3 克拉瑪法則、三角／反三角、對數、dB 換算、單位換算、向量、微積分、進位轉換、內插
- **元件工具**：E 系列標準電阻值、555 計時器、RC 時間常數、LED 限流電阻、齊納二極體、變壓器
- **雙埠網路**：2×2 矩陣加、乘、行列式、反矩陣等運算
- **波德圖 & 濾波器**：RC／RL 高低通的截止頻率、時間常數，並繪製增益與相位圖

## 技術與依賴
- 單檔 HTML PWA（`index.html` 內含全部 HTML/CSS/JS），`manifest.json` + `sw.js` 提供安裝到主畫面與離線快取。
- 函式庫（cdnjs）：math.js（表達式與複數運算）、Chart.js（波德圖）；相量圖以 Canvas 繪製
- 輸入暫存在 localStorage（`cmv2_` 開頭的 key）
